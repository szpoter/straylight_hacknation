## This repository

- Standalone sandbox for the mascot "Bąbelek". Mascot and animation work happens here, separate from the team's ZUS app, so nothing gets mixed up; the finished `components/mascot/` is moved into the app later.
- Stack: Next.js 16 (App Router, no `src/`), React 19, Tailwind CSS v4 (`app/globals.css`), TypeScript strict. Package manager: npm.
- Mascot docs: `MASCOT.md` (brief) and `docs/mascot/` (spec, tech stack, visual verification, sources). Reference image: `design/mascot/base.jpg`.
